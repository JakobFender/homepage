05 — Web demos

A collection of small interactive tools created using AI. Usually coded in an afternoon.

  • Web demo ↗ Distribution Playground An interactive web app for exploring 24 common probability distributions, from Normal and Beta to Poisson and Negative binomial. You can adjust parameters with sliders, switch between PDF and CDF, and overlay random samples. A built-in Fit game hides a target distribution and challenges you to match it by tuning parameters.
  • Web demo ↗ Gramma An memory game helping you learn all 24 greek letters. You can monitor your progress on the inbuild dashboard.
  • Web demo ↗ Regularization Playground An interactive web app for building intuition about regression, overfitting and regularization. You can add and drag data points, choose polynomial, RBF or Fourier features, and compare ridge, lasso and elastic net along the regularization path. A built-in Challenge mode hides a function and asks you to tune the penalty so the model generalizes to unseen test points.
  • Web demo ↗ Reinforcement Learning Playground An interactive web app with sixteen algorithms from Sutton & Barto's Reinforcement Learning: An Introduction, from bandits and dynamic programming to Q-learning, MCTS and actor-critic. Run them live on editable gridworlds, the 10-armed testbed and cart-pole, and watch values, policies and learning curves update as they train.
